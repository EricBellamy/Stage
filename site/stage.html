Set up in a minute

Install

Open the disk image, drag Stage to Applications and open it from there. macOS asks once whether to open an app downloaded from the internet; choose Open.

Connect your agents

Add Stage's MCP server to each agent you use by running its command below in Terminal.

Ask for designs

Start a new agent session and ask for designs on Stage, for example:

“Make three onboarding screens for my app on Stage.”

Claude Codeclaude mcp add --scope user stage -- /Applications/Stage.app/Contents/MacOS/Stage --mcp
Codexcodex mcp add stage -- /Applications/Stage.app/Contents/MacOS/Stage --mcp

Stays on your Mac

Designs, marks and history are saved on your Mac. There's no account, and designs can't reach the network. Apart from its daily update check, Stage talks only to apps on your Mac.

Updates by itself

Stage checks once a day and installs signed updates when it quits, or once your agents have been quiet for an hour, so their work isn't interrupted.

Signed and notarized

Stage is signed with a Developer ID and notarized by Apple. Each update is verified before it installs.
